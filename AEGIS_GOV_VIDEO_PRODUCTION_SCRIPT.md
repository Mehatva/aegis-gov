## 🛡️ TOP 3 Q&A CHEAT SHEET (FOR YOUR 4-MINUTE Q&A)

1. **If asked: *"What if the LLM hallucinates an invariant?"***  
   *Answer:* *"The LLM does NOT evaluate the invariant. The LLM only extracts raw text data into numbers. The invariant check is classical Python arithmetic (`quoted > baseline * 1.15`). An LLM cannot hallucinate past a Boolean check."*
